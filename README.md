# AI-Based Student Dropout Risk Prediction

## Overview

AI-Based Student Dropout Risk Prediction is a machine learning-powered educational analytics system designed to identify students who are at risk of dropping out. The system analyzes academic performance, attendance records, behavioral patterns, and student engagement data to predict dropout probability using artificial intelligence and predictive analytics.

The project helps educational institutions take early preventive actions and improve student retention through intelligent monitoring and real-time insights.

---

## Features

- Student dropout prediction using Machine Learning
- Attendance and academic performance analysis
- Risk score generation
- Early warning alerts
- Interactive dashboard visualization
- Predictive analytics and reporting
- Real-time student monitoring

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/AI-Dropout-Prediction.git
```

Go to project directory:

```bash
cd AI-Dropout-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
streamlit run app.py
```
